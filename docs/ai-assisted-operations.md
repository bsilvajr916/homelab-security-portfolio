# Use of AI as a Support Tool

AI is one of several resources I use while working on this homelab.

I treat it more like a technical assistant or guide than an automation system that makes decisions for me.

## What I use it for

- explaining unfamiliar concepts
- suggesting troubleshooting steps
- helping review logs or configuration
- reviewing or drafting small scripts
- helping organize documentation

## How I use it

AI suggestions are treated the same way I would treat advice from documentation, a forum, or another technical resource: useful input that still needs to be checked.

For important infrastructure changes, I rely on direct testing such as:

- SSH login tests
- firewall and network reachability checks
- service health checks
- storage checks
- backup integrity checks
- restore checksum comparisons

The basic process is:

`understand → change → test → document`

The goal is to use AI as a helpful assistant while keeping the actual homelab state verifiable through normal technical checks.
